# ✉️ 네이버 메일을 활용한 B2B 제안서 HTML 템플릿 테스트 발송 가이드

본 문서는 삼협철망 B2B 용접철망 제안서 HTML 템플릿을 네이버 메일 계정(`samhyupm@naver.com`) 및 외부 SMTP 연동을 통해 테스트 발송하는 세팅 방법과 스크립트 실행 절차를 설명합니다.

---

## 1. 네이버 메일 외부 SMTP 연동 설정 (필수)

외부 프로그램(파이썬 스크립트 등)에서 네이버 SMTP 서버를 사용해 메일을 전송하려면, 먼저 네이버 메일함 설정에서 **외부 메일 발송 권한(SMTP)**을 허용해야 합니다.

1. **네이버 메일(https://mail.naver.com)**에 로그인합니다.
2. 좌측 메뉴 맨 하단에 있는 **`[환경설정]` (톱니바퀴 모양 아이콘)**을 클릭합니다.
3. 상단 탭에서 **`[POP3/IMAP 설정]`**을 클릭한 뒤, 바로 아래 서브 탭에서 **`[IMAP/SMTP 설정]`**으로 이동합니다.
4. **`[IMAP/SMTP 사용]`** 항목을 **`[사용함]`**으로 체크한 후 하단의 **`[확인]`** 버튼을 눌러 설정을 저장합니다.

> [!NOTE]
> 해당 설정이 `사용함`으로 켜져 있지 않으면 메일 전송 시 `535 Username and Password not accepted` 오류나 연결 거부 오류가 발생합니다.

---

## 2. 계정 유형별 로그인 비밀번호 세팅법

네이버 로그인 환경에 따라 터미널(명령 프롬프트) 창에 입력해야 하는 비밀번호 유형이 다릅니다.

### 💡 유형 A. 단체 회원 계정 (`samhyupm` 등)
* **특징**: 단체 회원은 개인 회원과 달리 스마트폰 기기 연동을 통한 2단계 인증이 불가능합니다.
* **입력할 비밀번호**: 평소 네이버에 로그인할 때 사용하시는 **단체 계정 자체의 마스터 비밀번호**를 입력하시면 됩니다.
* **주의**: 단체 계정에 소속된 직원 개별 멤버 ID의 비밀번호가 아닌, 단체 아이디 대표 비밀번호를 입력해야 인증이 성공합니다.

### 💡 유형 B. 개인 계정 (2단계 인증이 활성화된 경우)
* **특징**: 2단계 인증이 켜진 개인 계정은 일반 로그인 암호 입력을 차단합니다.
* **입력할 비밀번호**: 네이버 보안설정에서 발급받은 **16자리 영문 일회용 '애플리케이션 비밀번호'**를 입력해야 합니다.
* **발급 경로**: 
  1. 네이버 로그인 후 **[내 정보]** ➡️ **[보안설정]** ➡️ **[2단계 인증 관리]** 클릭
  2. 페이지 하단 **[애플리케이션 비밀번호 생성]** 코너로 이동
  3. 종류 선택(예: 아웃룩 등 임의 기재) 후 **[생성]** 클릭
  4. 발급된 **16자리 영문 암호**를 복사하여 파이썬 스크립트 실행창에 비밀번호 대신 붙여넣기

## 3. 테스트 발송 스크립트 실행 방법

작성해 드린 발송 전용 스크립트는 **보내는 메일 주소**, **받는 메일 주소**, **비밀번호**를 각각 명령창에서 직접 타이핑하여 입력할 수 있도록 구성되어 있습니다.

1. PC에서 **명령 프롬프트(CMD)** 또는 **PowerShell** 창을 엽니다.
2. 아래 실행 명령어를 복사하여 붙여넣고 엔터(Enter)를 누릅니다:
   ```bash
   py c:\Users\Administrator\.gemini\antigravity\scratch\send_test_email.py
   ```
3. 안내 프롬프트에 따라 아래 값을 차례대로 입력합니다:
   * **보내는 사람 네이버 이메일**: 발송에 사용할 네이버 계정 주소를 적습니다. (엔터를 바로 치면 기본값인 `samhyupm@naver.com`이 지정됩니다.)
   * **받는 사람 이메일 주소**: 제안서를 전송받아 검증할 수신자 주소(예: 지메일, 개인 네이버 메일 등)를 입력합니다. (엔터를 바로 치면 본인 메일인 `samhyupm@naver.com`으로 수신됩니다.)
   * **네이버 비밀번호**: 보내는 사람으로 지정한 네이버 계정의 로그인 비밀번호(혹은 개인 2단계 인증용 앱 비밀번호)를 입력하고 엔터를 누릅니다.

4. 성공 시 화면에 아래와 같은 문구가 출력됩니다:
   ```text
   SMTP 서버 연결 시도 중 (smtp.naver.com:465)...
   로그인 성공! 메일을 전송하는 중...

   🎉 메일 전송이 완료되었습니다!
   ```
