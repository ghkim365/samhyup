# 네이버 검색광고 UTM 파라미터 및 키워드 자동 추적 설정 가이드

본 문서는 삼협철망 및 대흥정밀 B2B 카탈로그/견적 포털에서 네이버 파워링크 키워드 광고 유입을 자동으로 분석하고, 실제 어떤 키워드로 유입된 고객이 견적을 문의했는지 실시간으로 트래킹하기 위한 설정 및 운영 가이드입니다.

---

## 1. 작동 원리 및 시스템 연동 방식

### 💡 네이버 광고 {keyword} 치환 원리
* 네이버 검색광고는 연결 URL 뒤에 `{keyword}` 치환 기호를 넣는 것을 공식 지원합니다.
* 사용자가 네이버에서 **"용접철망"**을 검색하고 광고를 클릭하면, 네이버 광고 엔진이 실시간으로 `{keyword}` 부분을 검색 단어인 `용접철망`으로 바꾸어 사용자 브라우저를 접속시킵니다.
* 예: `.../index.html?utm_term={keyword}` ➡️ `.../index.html?utm_term=용접철망`

### 🤖 웹사이트 내 자동 추적 로직 (연동 완료)
* **방문 시점**: 사용자가 광고를 타고 랜딩 페이지(`index.html`)에 접속하면, 웹사이트 내부 스크립트(`app.js`)가 URL 뒤의 `utm_term` 파라미터 값을 파싱하여 브라우저 세션 스토리지(`sessionStorage`)에 안전하게 임시 보존합니다.
* **견적 제출 시점**: 고객이 견적 양식을 모두 작성하고 `전송하기` 버튼을 누르면, 시스템이 세션 스토리지에서 보존 중이던 유입 키워드를 꺼냅니다. 그 후, **"희망 규격 및 요청 수량"란 하단에 자동으로 덧붙여서** 전송을 수행합니다.
  > **[자동 삽입 예시]**
  > * 고객 입력값: `Ø2.2 x 50x50 50장 단가 및 납기 문의합니다.`
  > * 시스템 자동 삽입: `[네이버 광고 유입 키워드: 용접철망]`
* **수신 및 확인**: 이메일 알림 본문, 구글 스프레드시트 대장, 그리고 관리자 대시보드(`dashboard.html`)의 상세 내용 창에서 유입 키워드를 직관적으로 확인할 수 있습니다.

## 2. ⚙️ 네이버 검색광고 설정 방법 (광고주 수행 작업)

네이버 검색광고주센터(searchad.naver.com)에 로그인하신 후, 파워링크 광고 소재의 **연결 URL(랜딩페이지 주소)**을 아래와 같이 등록 및 교체해 줍니다.

### 📌 삼협철망 설정 주소
* **표시 URL**: `http://www.samhyup.com` (기존 홈페이지 주소 그대로 유지)
* **연결 URL (랜딩페이지)**: 
  ```text
  http://www.samhyup.com/catalog/index.html?utm_source=naver&utm_medium=cpc&utm_term={keyword}
  ```

### 📌 대흥정밀 설정 주소
* **표시 URL**: `http://daeheungsteel.co.kr` (기존 홈페이지 주소 그대로 유지)
* **연결 URL (랜딩페이지)**: 
  ```text
  http://daeheungsteel.co.kr/catalog/index.html?utm_source=naver&utm_medium=cpc&utm_term={keyword}
  ```

> **⚠️ 주의사항**
> * 연결 URL 주소 맨 뒤의 `{keyword}`는 중괄호(`{ }`)를 포함하여 **적힌 문자 그대로 입력**하셔야 네이버 광고 엔진이 정상적으로 실제 검색어로 치환해 줍니다.
> * 주소를 변경한 후 저장하면 네이버 측에서 정상 연결 여부 검수를 위한 심사가 진행되며, 승인까지 영업일 기준 약 1~2일이 소요됩니다.

## 3. 🧪 정상 작동 사전 검증 방법

네이버 광고 심사 승인 대기 기간 동안, 또는 세팅 후 작동 여부를 테스트하려면 아래 테스트 방식을 통해 임의로 키워드를 대입하여 검증하실 수 있습니다.

1. **테스트 URL 접속**
   * 웹 브라우저 주소창에 아래 테스트용 주소를 복사해 입력하고 사이트에 들어갑니다.
   * `http://www.samhyup.com/catalog/index.html?utm_source=naver&utm_medium=cpc&utm_term=테스트키워드`
2. **견적 문의 작성 및 제출**
   * 화면 하단의 견적 문의 양식에 테스트용 정보(회사명, 연락처 등)를 적고 제출 버튼을 누릅니다.
   * *주: 대흥정밀도 동일하게 끝에 `&utm_term=테스트키워드` 형태로 테스트할 수 있습니다.*
3. **결과 확인**
   * 네이버 메일함 또는 관리자 대시보드의 최신 견적 상세 모달을 열어봅니다.
   * 규격/수량 텍스트 끝단에 **`[네이버 광고 유입 키워드: 테스트키워드]`** 문구가 정상적으로 포함되어 있으면 시스템 연동이 완벽하게 성공한 것입니다.
