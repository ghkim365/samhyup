# ✉️ 삼협철망 B2B 인프라 운영 가이드
## - 이메일 발신/수신 이원화 및 네이버 블로그 안전 발행 전략 -

본 문서는 삼협철망 B2B 영업 마케팅 인프라(이메일 문의 연동 및 네이버 블로그 포스팅)의 보안 이슈를 우회하고 마케팅 효과를 극대화하기 위해 실무 담당자가 준수해야 할 운영 전략을 설명합니다.

---

## 1. B2B 견적 메일 연동: 발송/수신 이원화 (Dual-Email Strategy)

### 🔴 기존 방식의 문제점 (네이버 단체 메일 한계)
* 삼협철망 공식 메일 주소인 `samhyupm@naver.com`은 **단체 계정**으로 등록되어 있습니다.
* 네이버 단체 계정은 2단계 기기 인증이 불가능하며, 외부 프로그램(SMTP) 연동 시 잦은 보안 정책 변경과 차단으로 인해 자동 견적 알림 메일 발송이 자주 끊기는 문제가 발생합니다.

### 🟢 해결책: Gmail 발송 + 네이버 수신 이원화 적용
* **수신(Inbox) - 기존 유지**: 네이버 광고, 웹사이트, 블로그 등 기존 모든 채널에 노출되는 대외 연락처는 기존 그대로 **`samhyupm@naver.com`**을 사용합니다.
* **발송(SMTP/API) - 지메일 변경**: 구글 광고 운영용으로 새로 개설한 회사 지메일 계정 **`samhyupmesh@gmail.com`**을 발송 전용 엔진으로 설정합니다.
* **동작 프로세스**:
  1. 고객이 모바일 카탈로그에서 B2B 견적을 요청합니다.
  2. 시스템(GAS/SMTP)이 `samhyupmesh@gmail.com`을 사용하여 발송 요청을 보냅니다.
  3. 담당자 메일인 `samhyupm@naver.com`으로 실시간 견적 접수 알림이 즉시 수신됩니다.

### 🎯 이원화 도입에 따른 기대 효과
1. **보안 스트레스 제로**: 담당자가 네이버의 까다로운 2단계 인증이나 단체 비밀번호 연동을 관리할 필요가 전혀 없습니다.
2. **높은 발송 성공률**: 지메일의 안정적인 인프라를 사용하므로 알림 메일이 누락되거나 스팸으로 분류될 확률이 현저히 낮아집니다.
3. **영업 영속성 유지**: 외부 광고나 홍보물에 기재된 대표 이메일 주소를 변경할 필요가 없습니다.

## 2. 네이버 블로그 포스팅: 수동 복사-붙여넣기 권장 가이드

### ❌ 자동 포스팅 프로그램(매크로)을 사용하면 안 되는 이유
자동 포스팅 프로그램은 기술적으로 구현 가능하나, 네이버의 탐지 기술 고도화로 인해 다음과 같은 치명적인 마케팅 실패 요인이 발생합니다.

1. **블로그 저품질(Search Penalty) 지정 (최대 리스크)**
   - 네이버 검색 랭킹 알고리즘(C-Rank / DIA+)은 외부 프로그램이나 API를 통한 자동 발행 패턴을 실시간으로 탐지합니다.
   - 자동 등록이 감지되는 순간 블로그가 '저품질(Spam)' 판정을 받으며, 모든 글이 네이버 검색 결과(VIEW 탭, 스마트블록 등)에서 완전히 제외됩니다. 이는 마케팅 효과를 100% 상실시킵니다.
2. **보안 로그인(CAPTCHA) 상시 발생**
   - 가상 브라우저(Selenium 등) 로그인 시 스팸 방지 문자(영어/숫자 난수 입력 창)가 매번 나타나므로 실질적으로 100% 완전 자동화는 불가능합니다.
3. **공식 API 폐쇄**
   - 네이버는 무분별한 어뷰징을 방지하기 위해 2020년 5월부로 개인 블로그 글쓰기 오픈 API를 완전히 중단했습니다.

### 💡 가장 안전하고 확실한 솔루션: "1분 수동 포스팅"
저희가 제공해 드린 **블로그 미리보기 시안 페이지**를 활용하면 안전하게 네이버 블로그 상위 노출 효과를 누릴 수 있습니다.

* **발행 절차 (1분 소요)**:
  1. 관리자 대시보드 상단 메뉴에서 `✍️ 공식 블로그 시안`을 클릭하여 엽니다.
  2. 본문 영역의 글을 복사(Ctrl + C)하여 네이버 블로그 스마트에디터에 붙여넣습니다(Ctrl + V).
  3. 시안 파일의 이미지들을 각각 저장하거나 캡처하여 본문에 업로드합니다.
  4. '발행' 버튼을 클릭하면 완료됩니다.
