💡 에이전트 의견 및 권장 방향

대흥정밀 구축 노하우를 바탕으로, 삼협철망에도 "별도의 이력 관리(로그) 시트를 생성하여 데이터를 누적하는 구조"를 제안합니다.
메인 company 시트에서는 수식(MAXIFS, COUNTIF, TODAY)을 사용하여 최종 발송일과 발송 횟수, 경과일수를 자동으로 계산해 보여주고, 실제 메일 발송 시에는 Google Apps Script(GAS)를 통해 mail_log 시트에 지속적으로 로그 데이터를 축적해 나갑니다.

📊 1. 스프레드시트 구조 설계

[메인 시트: company] 구조 변경 및 수식 적용

열 번호 컬럼명 설명 / 역할 적용할 수식 또는 제어 방식
M열 발송대기 현재 회차 발송 대상 여부 (체크박스 또는 대기 기입) 직접 선택 혹은 스케줄러 자동 제어
N열 발송상태 메일 발송 작업 진행 상태 GAS가 발송 후 "성공" 또는 "실패" 기록
O열 최종 발송일 해당 업체에 마지막으로 메일을 발송한 날짜 =IFERROR(MAXIFS(mail_log!C:C, mail_log!D:D, C2), "")
(회사명 C2 기준 가장 최근 로그의 발송일자(mail_log!C:C) 매칭)
P열 발송경과 최종 발송일로부터 오늘까지 지난 일수 =IF(ISBLANK(O2), "", TODAY() - O2)
🎨 셀 색상 강조 자동화 (조건부 서식 설정 규칙)
10일차 도래 시 눈에 띄게 셀 색상을 변경할 수 있도록 다음과 같이 조건부 서식을 지정합니다.
규칙: P열 >= 10 인 경우 셀 배경색을 연한 오렌지/빨간색 계열로 채우기 적용.

⚙️ 2. Google Apps Script (GAS) 구현 코드

삼협철망의 스프레드시트에 연동할 신규 아웃바운드 자동화 스크립트 핵심 로직입니다.

var SS_ID = "YOUR_SPREADSHEET_ID_HERE"; // 삼협철망 스프레드시트 ID로 설정 function writeMailLog(companyName, email, round, status, detail) { try { var ss = SpreadsheetApp.openById(SS_ID); var log = ss.getSheetByName("mail_log"); if (!log) { log = ss.insertSheet("mail_log"); log.appendRow(["체크","연번","발송일자","회사명","이메일 주소","발송회차","발송상태","세부결과","비고"]); log.getRange("A1:I1").setFontWeight("bold").setBackground("#f1f5f9"); } var formattedDate = Utilities.formatDate(new Date(), "Asia/Seoul", "yyyy-MM-dd HH:mm:ss"); var lastRow = log.getLastRow(); var seq = (lastRow <= 1) ? 1 : lastRow; log.appendRow(["", seq, formattedDate, companyName, email, round, status, detail, ""]); } catch(e) { Logger.log("로그에러: " + e.toString()); } }
